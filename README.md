# Gana con tu Rifa Vene York

Página de rifas (hasta 1000 números), con cuenta regresiva, imágenes, pago por Zelle con comprobante, panel admin y ruleta.

## Publicar en GitHub Pages
1. Sube `index.html`, `README.md` y `.nojekyll` a un repositorio nuevo.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. En 1–2 minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Admin
Botón **Admin** (arriba a la derecha). Clave inicial: `2020` (cámbiala en Ajustes).

Nota: los datos se guardan en el navegador de cada visitante; para ventas reales con varios compradores hace falta conectar un servidor.
